## **Apple Orchard Collect**

Apple Orchard Collect is a game made with pygame software, your character (a squirrel) is trying to collect all 10 apples to win the game. However, with moving blocks that are moving horizontally across the screen makes this a little bit more difficult. The goal is to collect the apples and win the game without getting hit by the moving blocks.

#### **How the Apple Orchard Collect Runs**

In order to start the game you must have python and pygame installed on the device you are playing on. After those two things are downloaded find the start_game.ipynb
and press the play button to start. The display screen with appear and click play. 

#### **Controls and Interworking of Apple Orchard Collect**

Using the arrow keys you are able to move around the screen freely. You are also able to use a, s, d, w keys to move freely as well.
